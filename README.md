# LazyWGET

## Introducere
LazyWGET este un proiect care foloseste comanda **wget nerecursiv** pentru a descarca un singur fisier HTML, il parseaza si descarca recursiv resursele HTML referite de acesta.

## Features
- **Preia ca argument un link, de la tastatura.**(de forma https://site.tld/A.html)
- **Descarca fila HTML gasita intr-un fisier specificat.**(doar daca este dat ca un **al doilea argument**)
